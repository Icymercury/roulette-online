## 一、你拍的三条，落地成这样

| 你的裁定 | 落地方式 |
|---|---|
| ① 单人**吃**服务端规则，但**每次重启客户端自动回默认** | 单机页启动时**只拉一次** `/rules.json`，拿到就注入引擎；**绝不写 localStorage** ⇒ 关掉重开必定回到默认。改了规则又是新的一局，不会"记仇" |
| ② 管理台**不许异地访问**，它是服务端的"内嵌终端"，只有开服务器的人能用 | 管理台跑在**独立端口（游戏端口 + 1000）且只监听 `127.0.0.1`**；`admin.html` **故意不进静态白名单**。两道锁：穿透只转发游戏端口（管理端口在链路外）+ 游戏端口取 `admin.html` 直接 404 |
| ③ 不做预设方案 | 没做。规则页只给"逐项改"和"恢复默认" |

另外你最早提的第四项（客户端不要浏览器的样子、要有独立 UI）—— 落地为
**`start.html` 启动页 + 独立视觉**（暗底 + 金 + SVG 转盘 + 卡片式按钮），
管理台用同一套视觉。**没有走彻底原生重写**（那要双份代码，规则漂移风险太大）。

## 四·五、V16.1 追加：一键穿透 + 默认房间码（当天下午你提的）

### 一键穿透（管理台点一下，不用记命令）

原来要你自己开个窗口敲 `cpolar http 8080`。现在管理台上有：

| 控件 | 作用 |
|---|---|
| **开穿透** | 服务端替你拉起 `cpolar http <端口>`，最多等 15 秒抓网址，拿到就显示在上面 |
| **关穿透** | 关掉隧道（免费版域名本来也不固定，玩完关掉更安全） |
| **cpolar 程序位置** + 浏览… / 自动查找 | 选一次就**记住**（写进 `state.json`），以后不用再选 |
| 状态徽章 | 「未开启 / 已开启·等网址 / 已开启·有网址」；进程报错会把原因显示出来 |

- 自动查找会翻：`C:\Program Files\cpolar`、`Program Files (x86)`、`C:`、`D:`、`E:\cpolar`（你现在装这儿），以及 PATH。
- **浏览…** 弹的是 Windows 原生文件选择框（只有房主本机能弹，别人够不到管理台）。
- 服务端退出（Ctrl+C / 关窗口）时会**把穿透一起收掉**，不会留一个还在公网暴露 8080 的进程。
- 仍然保留"你自己在外面开隧道"这条路 —— 服务端照样能自动发现并显示网址。

### 默认房间码 584520

- 开房就带码，**不用设也挡人**；房主随时能在管理台改。
- 🔴 **每次重启服务端都回到 584520**（不记住你改过的那个）—— 这是你要的，省得重启后对着旧码发懵。
- 命令行显式给码时以命令行为准：`生死转盘-服务端.exe 8080 我的码`。
- 客户端点带码的服务器时，**房间码框会预填 584520** —— 房主没改过码的话，朋友直接点「进房间」就进了，省一次手敲。
- 测试要"无码直接进房"时传环境变量 `RR_ROOM_CODE=`（空）关掉默认码。

## 五、规则页能改什么 / 不能改什么

| 能改 | 护栏 |
|---|---|
| 转盘概率（5 项） | **之和必须正好 100**，否则当场禁用保存 |
| 金币格收益、利息「每 N 金 +M」 | ≥ 0；利息分母 ≥ 1 |
| 四个道具的售价 | 0–99999 |
| 减少转数：限购次数 / 每次减几转 | 0–99999 |
| 香蕉皮：生效转数 | 0–99999 |
| 三个模式的血上限 | **1–99** |
| 死神追猎目标转数 | ≥ 1 |

**故意不开放的**：利息「本金封顶 500」和「71 转后每买一次翻倍」——
这两条是防僵局的两条命根子（16000 局零僵局就是靠它们，且做过 2×2 消融）。
改它们必须重跑 `sim-v10-stalemate.js`，不是改个数那么简单。

改动一律**下一局生效**，已经在局中的人不受影响。

## 六、这轮修掉的坑（值得记住）

1. **启动页才是 App 的第一屏，但打包只抽验了联机页** ⇒ 首页要是死的，App 一打开就废。
   现在 APK 打包会**把 `start.html` 抽出来单独验一遍**。
2. **启动页验收第 ⑥ 条把自己误伤了**：按文字搜 `engine.js`，被页脚「规则由 engine.js 提供」
   命中 ⇒ 判据改成只查 `<script` 标签。
3. **管理端口默认取 `PORT+1` 会撞车**：测试常同时起多个服务端，`PORT+1` 正好是下一个实例的
   游戏端口 ⇒ 改成 `PORT+1000` + 占用时自动 +1 重试 40 次。
4. **discovery 测试随机红**：广播包在真实网络里会丢，而测试只发一次、只等 800ms，
   于是"重启后设置恢复"这类断言**今天红在 ⑨、明天红在 ⑩**。
   改成"没回音就再问（最多 3 次，按 id 去重）"+ 单独断言"UDP 端口真起来了"。连跑三次 46/46。
5. 手写 for 循环跑测试**漏过 engine-modes 那一整套 125 条** ⇒ 清单钉进 `build/run-all.js`。
6. **默认房间码会连带打崩 600 条断言**：所有测试服务端都是"无码直接进房"的假设。
   ⇒ 加了 `RR_ROOM_CODE` 环境变量（空串 = 关闭默认码），六处起服务端的地方统一传它；
   再单独开一台**保留默认码**的服务端专门验"默认码生效 / 可改 / 重启回默认"。

## 七、V16.2 修的两个客户端问题（2026-09-29 傍晚）

赐红反馈：「客户端在我电脑上打不开，显示 404」+「为啥客户端也有拉起一个命令行？」

### 问题一：客户端 exe 双击后是 404（真 bug，V16 连锁漏网）

**现象**：双击 `生死转盘-客户端.exe`，自动弹出来的窗口是一片 `404`。

**根因**：`pc-client.js` 的 `main()` 里把这个窗口开成了
`http://127.0.0.1:<选择页端口>/client.html`，而**本机那个小服务只认 `/` 和 `/index.html`**，
其余路径一律走末尾的 404 分支。两者对不上，所以第一眼就是 404。

V16 改「`/` 从游戏页变成启动页」时，连锁清单里列了 5 处，**漏了 `pc-client.js` 自己这一处** ——
把「服务端 `/` 改了」和「本机小服务 `/` 改了」搞混了。
（真正连上服务器之后用的 `/client.html` 属于**对端服务端**，与本机小服务无关。）

**修法**：改回 `/`。同时在 `build/build-pc-client.js` 的冒烟里**加了两条断言**：

- `★ 双击 exe 自动打开的窗口不是 404（本机小服务没有 /client.html）`
- `★ 自动打开的 / 是真选择页（不是空白也不是 404）`

原来 36 项冒烟**一条都没验过**"自动打开的那个 URL 取得到东西"，所以这个 bug 才能溜过去。

### 问题二：客户端也弹一个黑窗口（Node SEA 固有行为）

**根因**：两个 exe 都是把 `node.exe` 复制一份再注入 SEA blob，而 `node.exe` 的 PE 头里
`Subsystem = 3 (WINDOWS_CUI)` —— 控制台程序，双击必带黑框。

- **服务端**的黑框是**故意的**：那是它的脸，横幅（名称 / 编号 / 房间码 / 各条地址）全印在里面。
- **客户端**的黑框是**副产品**：它的界面是自己开出来的独立窗口，黑框纯属噪音。

**修法**（赐红选「隐藏但留个开关」）：

1. `build/build-pc-client.js` 打完包后把 PE 头的 Subsystem 从 `3` 改成 `2 (WINDOWS_GUI)`。
   🔴 **只改客户端，服务端绝不改**。位置：`e_lfanew(0x3C)` → `+4+20+68 = +92 (0x5C)`，
   改前先认 PE 签名和 Magic（0x20B / 0x10B），改完落盘再读一遍校验。
2. 代价对策 —— **日志落盘**：GUI 下没有 stdout，`console.log` 会被静默丢掉。
   所以 `pc-client.js` 把全部输出**同时写一份**到 `%TEMP%\生死转盘-客户端.log`（每次启动截断）。
3. **开关**：设 `RR_DEBUG_WINDOW=1` 时，客户端检测到自己没有真控制台，
   就用 `cmd /c start` 开一个控制台窗口**重新拉起自己**，然后原进程退出。
   正常双击不弹窗，排障时才有。

**验证**：
- 客户端冒烟 **36 → 41 项全绿**（新增 PE 子系统、日志落盘、自动打开路径 3 条）。
- 真机实测：真服务端(:8301) + 真客户端，`/` → **200**、`/client.html` → **404**（确认根因）、
  UDP 扫到 1 台、日志文件存在且含横幅。
- `RR_DEBUG_WINDOW=1` 实测：日志里出现"这是调试窗口"提示，且**横幅与提示各只出现 1 次**
  （说明重开时父进程没污染日志）。
