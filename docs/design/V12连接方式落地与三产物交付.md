## 二、先说那条硬伤（V11 提过，这里给最终结论）

**「服务器编号」是名字，不是地址。**

编号是从你的主机名和网卡 MAC 算出来的，它**推不出** `10.113.132.95:8080`。
中间必须有一层「查号台」——要么局域网广播（同 WiFi），要么一台公网中继服务器。
没有中继，就**不可能**做到"在任何网络下只输个编号就能连"。

所以最终方案是：

| 场景 | 怎么连 | 要输什么 |
|---|---|---|
| 同一个 WiFi / 路由器 | 打开 App 或客户端 → 列表里点一下 | **什么都不用输** |
| 异地（不同网络） | 房主开 Tailscale，把地址发过去 → 对面粘进手动框 | 输一次地址（一次性） |

> 想做「任何网络只输编号」也行，但那要一台有公网 IP 的服务器做中继（VPS + 域名 + 带宽），
> 而且中国家庭宽带基本拿不到公网 IPv4。**这轮不做**，等你觉得真有必要再谈。

## 三、三样东西，三张脸

| 产物 | 谁用 | 打开后看到什么 | 要不要装 |
|---|---|---|---|
| `生死转盘-服务端.exe`（83 MB） | **房主** | 黑窗口：服务器名称 / 编号 / 房间码 / `★ 别人连这一行` | 不用装，双击就跑 |
| `生死转盘-客户端.exe`（83 MB） | **PC 玩家** | 一个「找服务器」窗口（**无地址栏**）→ 点一台 → 再弹一个无地址栏的游戏窗口 | 不用装，双击就跑 |
| `生死转盘-手机版.apk`（0.1 MB） | **手机玩家** | 打开就是服务器列表，点一下进游戏 | 要装（侧载） |

**为什么 PC 客户端不内置游戏页面**：游戏页直接从服务器加载
（`http://<服务器>:<端口>/client.html`），于是页面里的地址天然就是对的 ——
客户端只管"找到谁、连谁"，游戏本体永远由服务端提供，所以**永远不会出现两端版本不一致**。

两个 exe 各有 83 MB，是因为各自内嵌了一份完整的 Node 运行时（对方不用装 Node）。
APK 只有 0.1 MB，因为它用的是手机自带的 WebView。

## 四、服务器身份三件套

| | 谁定的 | 能不能改 | 例子 |
|---|---|---|---|
| **服务器编号** | 设备自己算（主机名 + 物理网卡 MAC） | **不能改**（它不是设置项） | `942-LRZ` |
| **服务器名称** | 默认「`<主机名>` 的房间」，房主可改 | 房主在大厅里改，最长 20 字，落盘 | `阿红的房间` |
| **房间码** | 默认无（任何人可加入） | 房主在大厅里改或清空，最长 12 字，落盘 | `7788` |

两个要注意的点：

1. **房间码只挡"新加入"的人。** 改码不会把已经在房里的人踢出去 —— 他们早就进来了。
   这比"踢人重进"友好得多。
2. **房间码不会被广播出去。** 局域网里别人扫到的卡片上只有「要不要房间码」这一个标志，
   没有码本身。点了带码的服务器，客户端才弹输入框。

## 五、自动发现是怎么做的（两条路）

浏览器和 WebView 里的 JS **发不了 UDP 广播**（安全沙箱不允许）。
所以"扫描局域网"这件事必须在原生层做：手机由安卓壳的 Java 做，PC 由客户端 exe 做，
扫完把结果喂给页面。纯浏览器打开网页时没有扫描能力，只能手输地址。

原生层有**两条互相兜底的路**：

| | 谁主动 | 防火墙要求 | 通了会怎样 |
|---|---|---|---|
| ① 主动询问 | 我们广播「谁在？」 | **电脑那边**要放行入站 UDP 广播 | 服务端单播回一张卡片 |
| ② 被动心跳 | 服务端每 3 秒自己广播一次 | **我们这边**要能收到入站广播 | 直接收下卡片 |

**为什么两条都要**：① 有个很常见的死法 —— 电脑上第一次双击服务端时 Windows 弹
「是否允许访问网络？」，用户点了「取消」或直接关了弹窗 ⇒ 电脑收不到手机的询问 ⇒
**列表永远空的**。这时候只有 ② 能救。两条路的防火墙要求正好互补，所以都留着。

两边的卡片先进同一张共享表（9 秒过期），再由任一方把整张表推回页面，
所以不会出现"后到的那条把先到的那条挤掉"。

   但保险起见还是点允许。

   打包发给别人时**别把这个目录整个压缩**（会带上你的存档），只发需要的文件。
5. 服务端第一次退出时会把当前对局落盘；下次启动自动恢复，这是设计如此。

## 九、你下一步要做的事

1. **电脑**：双击 `生死转盘-服务端.exe` → 防火墙点「允许」→ 记住横幅上的**服务器编号**。
2. **手机**：装 `生死转盘-手机版.apk`（旧版本如果装不上，先卸载再装）→
   连**和电脑同一个 WiFi** → 打开 App。
   - 正常：首页直接列出「`<你的主机名>` 的房间 `942-LRZ`」，点一下就进游戏大厅。
   - 不正常：把手机浏览器打开 `http://<横幅上那条地址>` 试一次 ——
     打得开说明网络通（问题在 App），打不开就是防火墙或 AP 隔离。
3. **PC 玩家**：双击 `生死转盘-客户端.exe` → 弹出「找服务器」→ 点列表里的服务器进游戏。
4. **异地朋友**：两边都装 Tailscale → 房主把 Tailscale 地址（`100.x.x.x:8080`）发过去 →
   对面粘进客户端或 App 的**手动地址框** → 连接。
