# V17 界面重构 · 落地说明

> 时间：2026-09-29 晚 · 承接 V16.2（客户端 404 + 黑窗口）
> 本轮**一句规则都没改** —— `engine.js` 零改动，全部是界面与启动器层面的重构。

---

## 一、为什么要改（赐红原话拆出来的四条）

> 「客户端还是没有选择单人模式还是联机模式的选项，直接打开是这个界面，PC 玩家永远玩不了单机模式。
> 把上方的搜索服务器和自行连接字样删除，把血条对比放到上面，单人模式是把血条放上面，
> 要连接服务器需要去单独的界面连接，这样不占用界面布局。」

| # | 问题 | 改法 |
|---|---|---|
| ① | PC 客户端第一屏就是「找服务器」⇒ **PC 玩家没有任何入口进单人模式** | 首屏改成「选玩法」（转盘 + 单人卡片 + 联机卡片），与手机端 / 服务端首页同一套视觉 |
| ② | 进房间之后，顶部「搜索服务器 / 自行连接」还一直占着版面 | 拆成 `#connectView` / `#gameView` 两个整屏，连上就自动收走连接屏 |
| ③ | 「谁快死了」得去右栏一张张卡片里读 | 全员血量做成**并排横条**钉在轮盘正上方 |
| ④ | 单机页血量躲在最左栏底下 | 单机页也搬到顶部（`剩 余 生 命` + 心 + 数字 + 条） |

三个选项都是赐红自己挑的：**照搬启动页** / **顶部横条·全员并排** / **独立连接页·回退可返回**。

## 二、完整规格（改完之后的样子）

### 2.1 PC 客户端首屏（`pc-client.js` 的 PICKER）

```
        转盘 SVG
      生 死 转 盘
        选一种玩法

  ┌──────────────────────┐  ┌──────────────────────┐
  │ 🎯 单人游戏          │  │ 👥 联机游戏          │
  │    不用连服务器      │  │    要房主开服务端    │
  │ 死亡轮盘 · 本地开跑  │  │ 对赌/追猎 · 局域网搜 │
  └──────────────────────┘  └──────────────────────┘
```

- 点**单人** → 本机小服务 `POST /play-solo` → Node 侧开一个**无地址栏独立窗口**，地址是
  `http://127.0.0.1:<本机小服务端口>/solo`。
- 点**联机** → 同页切到「找服务器」视图（列表 + 手动地址），带「← 返回 · 选玩法」退路。

### 2.2 联机页双视图（`client.html`）

| 屏 | 什么时候显示 | 内容 |
|---|---|---|
| `#connectView` | **没连着**（默认就是这个） | 名字 / 服务器列表 / 手动地址 / 房间码 |
| `#gameView` | **连上之后**（`ws.onopen`）自动切过去 | 顶部血条对比条 + 三栏布局 |

- 顶部工具条（模式 / 规则 / 音效 / 返回启动页）**只在游戏页显示**；
- 顶部只留一个连接入口按钮：没连着写「连接服务器」，已连着写「**换服务器**」；
- 连着的时候点进去有「← 返回游戏（已连上的那台还在）」，不会把人锁在连接页里；
- 断开连接（正常离开 / 自动加入失败）自动退回连接屏；
- 🔴 两个屏都**不写死 `display`**，由 `showView()` 统一加 `.on` —— 否则 `init()` 里任何一处
  抛异常都会留下一个空白页（V10 白屏事故同款）。

### 2.3 顶部血条对比条（两个页面同一套视觉）

一格 = 一个玩家：

```
 ┌─────────────────────────┐
 │ 赐红 · 我 · 房主   7/15 │   ← 名字 + 我 / 房主 标记 + 当前 / 上限
 │ ███████████░░░░░░░░░░░ │   ← 血条（条色随血量变）
 │ 轮到他                  │   ← 状态文案（轮到他/掉线/出局/已完成/读数/进度）
 └─────────────────────────┘
```

| 状态 | 视觉 |
|---|---|
| 我 | 金边 |
| 轮到他 | 绿边 + 内描边 |
| 血 ≤ 2 | 黄橙条 + 红色数字（`.warn`） |
| 满血 | 绿条（`.ok`） |
| 出局 | 整体变暗 |
| 掉线 | 灰掉（封存中） |
| 死神追猎 | 额外一条**绿色进度条**（目标 100 转的完成度） |

人多自动换行（`flex-wrap`），不会挤成一团。

**顺手删掉的重复**：房间卡片里那条血条没了（血量只留顶部一处），左栏「我」里那条 `myHpBar` 也没了
（保留 `生命 7/15` 这个数字 —— 客户端测试里「DOM 生命 === 服务端生命」断言的就是它）。

单机页则是**一格**的横条：`剩 余 生 命` + 七颗心 + 数字 + 条 + `第 N 转 · ☠ 镰刀已挥下`。
左栏「状态」里那条重复的「生命」数字一并删掉。

### 三条踩到的坑（都写进注释了）

1. **假 DOM 少了 `classList.toggle` 和 `document.querySelector` ⇒ 页面一进 `init()` 就炸。**
   这不是产品 bug，是测试能力缺口：真浏览器有这两个方法，假 DOM 没有，
   `showView()` 第一行就 `TypeError`。按项目硬规矩「假 DOM 必须照抄真环境的语义」补上 ——
   🔴 `toggle(name, force)` 给了第二个参数是**强制设成某个布尔**，不是取反；按取反实现的话
   `showView('game')` 会把游戏页关掉、把连接页打开，界面正好反过来，而且假 DOM 里**完全不报错**。
2. **`renderPlayersTicks()` 原来按下标取 `.pmeta`（`children[2]`）。** 卡片里那条血条一删，
   下标整体左移一格 ⇒ 它会摸到「进度条」而不是 meta，于是**计时静默失效**
   （找不到就什么都不做，不报错、测试也测不出来）。改成按 class 找。
3. **客户端 exe 里没有磁盘文件，`/play-solo` 走 `file://` 必翻车。**
   客户端 exe 历来「零内嵌」（联机页从服务器加载，保证版本一致）—— 但**单人模式没有服务器可加载**，
   所以单机页是唯一必须打进客户端 exe 的页面。现在 `soloSource()` 优先用构建期注入的
   `EMBEDDED_SOLO`，本机小服务把它发成 `/solo` + `/engine.js`；源码直跑时才读磁盘。
   （顺带解决了另一个隐患：不用赌中文路径在 `file://` 下的表现。）
